YOUR SETUP GUIDE

Find your coding space.

An environment gives you a place to write, run, and check your code. Start with one tool and get comfortable with it.

Start with VS Code on a computer

My suggested starting point is Python + VS Code + Microsoft's Python extension. An extension adds features to an editor. This one connects VS Code to your Python installation.

VS Code is the editor. Install Python separately using the installation guide.

01 · Set up VS Code

These steps are for Windows, macOS, or Linux. On a supported Chromebook, enable Linux first. For phones and tablets, use the Android, iPhone/iPad, or browser options.

  1. Download and install Visual Studio Code.
  2. Open its Extensions panel, search for Python, and install the extension published by Microsoft.
  3. Create a folder named python-practice. In VS Code, choose File → Open Folder and select it.
  4. Open View → Command Palette. Search for Python: Select Interpreter and choose your installed Python 3.
  5. Create a file named hello.py. The .py ending identifies it as Python code.

Write your first file

name = input("What is your name? ")
print("Hello,", name)

input() asks a question and waits for your answer. name stores the answer. print() displays it; the comma adds a space between the greeting and the name.

Save the file. Use the top-right play button's Run Python File in Terminal option. Click in the terminal, type your name, and press Enter.

Example session, if you type Bright:

What is your name? Bright
Hello, Bright

The terminal shows both the question and what you type. Choose “Run Python File in Terminal” so programs using input() can accept your answer.

02 · Other environments you can use

An IDE combines editing, running, and debugging tools. Debugging means finding and fixing problems in your program.

Thonny

Good for: a simple beginner workspace.

Thonny is designed for learning Python. Its Windows and Mac installers bundle Python, and its step-through debugger helps you follow what your program does.

Install it, create a file, save it with a .py ending, and select Run → Run current script.

Get Thonny ↗

IDLE

Good for: small scripts with a basic editor.

IDLE is Python's own editor and interactive shell. Some Python installations include it; Linux may require a separate IDLE package.

Open IDLE, choose File → New File, save your code, then choose Run → Run Module.

Learn about IDLE ↗

Jupyter

Good for: experiments, notes, charts, and data.

A notebook mixes text with small code sections called cells. Run a cell to see its result underneath. It works differently from running a whole .py file.

Try the browser demo. Download a copy of work you want to keep; a demo session is not permanent storage.

03 · A useful next step: virtual environments

A package is extra code you can install. A virtual environment keeps one project's packages separate from another's. You do not need extra packages for the first exercises here.

When you start using packages, open the VS Code Command Palette and select Python: Create Environment → Venv, then choose your installed Python. Select the new .venv interpreter when it is ready.

If something does not work

VS Code cannot find Python

Check Python with the command from the installation guide, restart VS Code, then run Python: Select Interpreter again.

I cannot type an answer

Use Run Python File in Terminal, then click the Terminal panel. The Output panel does not accept answers for input().

My file does not run as Python

Check that its name ends in .py, not .py.txt. Save it, open that file in the editor, and run it again.
