YOUR SETUP GUIDE

Get Python ready.

Follow the steps for your computer, check the installation, then move on to writing your first file.

First, what are you installing?

Python is the language you write. The interpreter is the program that reads and runs that code. An editor, such as VS Code, is where you write and save it.

A terminal is a window where you type commands. Enter the commands below in your terminal, not inside a Python file. Press Enter after each command.

You can keep using this site's practice runner without installing anything. These steps prepare your computer for full Python programs.

WindowsMacUbuntu / LinuxChromebookAndroidiPhone / iPadBrowser

01 · Windows

  1. Open Python's official download page and download the Python install manager for Windows.
  2. Open the downloaded installer, select Install, and follow its setup prompts.
  3. Open the Start menu, search for Terminal, and open it. Install the default Python runtime: 
    py install default
    If an older launcher does not recognize that command, use pymanager install default instead.
  4. Check that Python runs:
    py --version

You should see Python 3.x.x, with real version numbers in place of the x's.

Using an older .exe installer?

If its first screen offers Add python.exe to PATH, check that box before selecting Install Now. PATH helps your terminal find Python. This checkbox belongs to the older installer; the install manager uses a different setup flow.

02 · Mac

  1. Open Python's macOS downloads. Choose a stable Python 3 release and download its macOS installer.
  2. Open the .pkg file and follow the installer steps.
  3. Open Terminal using Spotlight search, then check the installation:
    python3 --version

You should see Python 3.x.x. Use python3 for the Mac commands in this guide.

If Python reports certificate errors when accessing secure websites, run Install Certificates.command from the Python folder in Applications.

Official macOS installation help ↗

03 · Linux: Ubuntu and other distributions

Ubuntu is a Linux distribution, meaning a version of Linux. Debian, Linux Mint, Fedora, and Arch are other examples. Python may already be installed. Open Terminal and check first:

python3 --version

On Ubuntu, Debian, Linux Mint, or Raspberry Pi OS, use these commands to install Python and its package and environment tools:

sudo apt update
sudo apt install python3 python3-pip python3-venv

sudo requests administrator permission. apt installs software. pip installs extra Python packages, and venv creates a separate space for a project's packages. Your password may show no characters as you type.

Then run python3 --version again. Keep the system's Python installation in place.

Official Ubuntu instructions ↗

Fedora Workstation

Python 3 is normally included. If needed, install it and pip with Fedora's package manager:

sudo dnf install python3 python3-pip
python3 --version

Fedora's Python guide ↗

Arch Linux

Use Arch's package manager. This command also updates your system, so review the changes before confirming:

sudo pacman -Syu python python-pip
python --version

Arch's Python guide ↗

Another Linux distribution?

Search your distribution's official software manager for Python 3. Package names and commands vary. Do not copy Ubuntu's apt commands into a distribution that uses another package manager.

04 · Chromebook

  1. Open Settings → About ChromeOS → Developers → Linux development environment and choose Set up.
  2. Follow the setup prompts, then open the Linux Terminal.
  3. Use the Ubuntu/Debian commands above to install Python, then check with python3 --version.

If Linux is unavailable or disabled on a school/work Chromebook, use the browser option. Availability depends on the device and its administrator settings.

05 · Android phones and tablets

Use an app that supplies a Python environment, or practice in your browser. Desktop Windows and Mac installers do not run on Android.

  1. Visit Termux's official website and follow its installation instructions for your Android device.
  2. Open Termux and run these commands one at a time:
    pkg update
pkg install python
python --version
  3. Check that it works:
    python -c "print('Python is ready!')"

pkg is Termux's package tool. Python runs inside the app. Some desktop packages and graphical programs may not work there.

06 · iPhone and iPad

Python runs inside an app on iOS/iPadOS rather than as a normal desktop installation.

  1. Open Pyto's official website and follow its App Store link. Check the current price and device requirements before installing.
  2. Open the app and create a Python script named hello.py.
  3. Enter the code below, then use the app's Run control:
    print("Python is ready!")

Expected output:

Python is ready!

Package and file access depend on the app. For no-install practice, use the browser option below.

07 · No installation: a browser

On a computer, tablet, or phone with a modern browser, open this practice website for the beginner lessons.

For notebooks, open Try Jupyter, choose a notebook demo, and create a Python notebook. Type print("Python is ready!") in a code cell and use Run. You should see Python is ready! underneath.

Browser demos have package and resource limits. Download your notebook to keep your work. Small screens are easier to use with a keyboard.

Check your desktop setup with one line

Windows terminal:

py -c "print('Python is ready!')"

Mac or Linux terminal:

python3 -c "print('Python is ready!')"

-c tells Python to run the code that follows. print() displays the text inside the quotes.

Expected output:

Python is ready!
“Command not found” or “not recognized”?

Close and reopen your terminal after installing. Try py on Windows or python3 on Mac/Linux. On Windows, confirm the install manager finished its setup. If needed, run pymanager install --configure.

Seeing >>> instead of a normal terminal?

You opened Python's interactive shell. Type exit() and press Enter, then run the terminal command above.
